# 💰 Personal Expense Tracker

A Python project to manage daily expenses, organize spending by category, and track total expenditure.

## ✨ Features

- ➕ Add expenses
- 📋 View all expenses
- 💵 Calculate total expenses
- 🏷️ Categorize expenses
- 📊 View category-wise spending summaries
- 🗑️ Delete expenses
- 💾 Store expenses permanently using JSON
- ✅ Validate expense amounts and user input

## 🛠️ Technologies Used

- Python
- JSON
- os module
- Git
- GitHub

## 📂 Project Files

| File | Description |
|---|---|
| `expense_tracker.py` | Code A: Basic expense tracker with categories, summaries, and delete functionality |
| `EXPENSE.py` | Code B: Expense tracker with permanent JSON storage |
| `.gitignore` | Prevents personal expense data from being uploaded |
